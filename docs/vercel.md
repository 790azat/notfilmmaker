# Деплой на Vercel

Laravel работает через community-runtime [vercel-php](https://github.com/vercel-community/php).
Файловая система Vercel только для чтения, поэтому нужны внешняя база и хранилище файлов.
Все настройки окружения (кэши в `/tmp`, логи в stderr, сессии в cookie, обход проблемы Neon с SNI) — в `api/index.php`.

1. **Проект**: импорт репозитория на Vercel, Framework Preset **Other** (остальное из `vercel.json`).
2. **База**: Storage → Neon (Postgres) → подключить к проекту. Vercel добавит `DATABASE_URL`, сайт подхватит его сам.
   Миграции и стартовые настройки запускаются автоматически при первом запросе к новому деплою (`AUTO_MIGRATE`).
3. **Файлы**: Storage → Blob (публичный) → подключить к проекту. Vercel добавит `BLOB_READ_WRITE_TOKEN`.
   Фото и видео из админки загружаются прямо из браузера в Blob, поэтому лимит Vercel 4,5 МБ на запрос не мешает.
4. **Переменные** (Settings → Environment Variables):

| Переменная | Значение |
| --- | --- |
| `APP_KEY` | вывод `php artisan key:generate --show` (обязательно) |
| `APP_URL` | `https://<домен>` |
| `CRON_SECRET` | любая длинная случайная строка (для ежедневного импорта с YouTube) |
| `MAIL_*` | необязательно: чтобы письма с формы контактов приходили на почту |

После изменения переменных сделайте **Redeploy**.

5. Откройте `https://<домен>/register` и создайте аккаунт — он станет админом.
