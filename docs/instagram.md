# Как подключить Instagram

Сайт забирает все посты из Instagram (фото, карусели, видео) через официальный API Instagram.
Для этого нужен токен доступа. Получить его нужно один раз, дальше сайт продлевает его сам.

## 1. Сделать аккаунт профессиональным

В Instagram: **Настройки → Тип аккаунта и инструменты → Переключиться на профессиональный аккаунт → Автор**.
Это бесплатно, а посты и подписчики остаются как были.

## 2. Создать приложение Meta

1. Откройте https://developers.facebook.com/apps и войдите через Facebook.
2. **Create app**. Вариант использования: **Manage messaging & content on Instagram**. Тип: **Business**. Название любое, например `notfilmmaker site`.
3. В приложении откройте **Instagram → API setup with Instagram login**.

## 3. Получить токен

1. В блоке **Generate access tokens** нажмите **Add account** и войдите в аккаунт `not_filmmaker`.
   Если Instagram попросит принять приглашение, откройте в Instagram **Настройки → Приложения и сайты → Приглашения тестировщикам** и примите его.
2. Напротив аккаунта нажмите **Generate token** и скопируйте токен (начинается с `IGAA…`).

## 4. Вставить токен на сайте

Админка → **Настройки → Instagram** → вставьте токен → **Подключить Instagram** → **Импортировать все посты**.

Импорт идёт порциями, кнопку можно не трогать, пока счётчик растёт. Потом новые посты
будут появляться сами раз в день. Лишнее можно скрыть или удалить в разделе «Работы».
