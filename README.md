# notfilmmaker — портфолио Грача Арутюняна

Сайт-портфолио режиссёра, оператора, фотографа и монтажёра: фильмы, короткометражки, сериалы, музыкальные клипы и фото.

- **Laravel 13 + Livewire 4**, Tailwind CSS 4, Vite.
- Три языка: армянский (по умолчанию), русский, английский. Переключатель в шапке; язык запоминается.
  Тексты интерфейса — `lang/{hy,ru,en}/site.php` и `admin.php`, тексты работ и настроек вводятся в админке на каждом языке.
- Публичные страницы: главная (шоурил фоном, избранные работы, услуги, свежие видео с YouTube), работы с фильтром и поиском,
  страница работы (плеер, описание, галерея с лайтбоксом), обо мне, контакты (форма → сообщения в админке).
- Админка `/admin`: работы (тексты на 3 языках, ссылка YouTube/Vimeo или свой видеофайл, обложка, галерея фото и видео,
  публикация, «на главной», порядок), сообщения с формы, настройки сайта (имя, тексты, контакты, соцсети, шоурил, картинки,
  цифры, SEO), пользователи, профиль.
- Регистрация: `/register`. **Первый зарегистрированный аккаунт становится админом**, после этого регистрация закрыта
  (можно открыть в настройках; новые пользователи получают доступ только когда админ даст им права).
- YouTube: новые видео канала сами появляются в «Работах» раз в день (Vercel Cron → `/cron/youtube`)
  и по кнопке «Забрать с YouTube» в админке. Ключ API не нужен, используется публичная RSS-лента канала.

## Локальный запуск

    composer install && npm install
    cp .env.example .env && php artisan key:generate
    touch database/database.sqlite && php artisan migrate --seed
    php artisan storage:link
    composer run dev

Откройте http://localhost:8000/register и создайте аккаунт админа.
